⚡ GET STARTED IN 3 MINUTES:

1. Download Node.js from https://nodejs.org (if you don't have it)

2. Open Terminal/Command Prompt and run:
   cd ShopPOS
   npm install
   npm start

3. Download "Expo Go" from Google Play Store on your Android phone
   Scan the QR code shown in terminal
   App appears instantly!

🏗️ TWO WAYS TO USE:

Option 1: Test with Expo Go (Free, Easy)
- npm start
- Scan QR code on your phone
- App works on your phone via Expo Go app

Option 2: Build APK (For permanent installation)
- Easy: eas build --platform android
- Hard: npx expo prebuild && ./gradlew assembleRelease
- Download APK and install on any Android phone

🔍 HOW TO USE:

Search:
  Type "FRESH" → See fresh products
  Type "MUTTON" → See mutton items  
  Type "N0027116" → Find by code
  
Select:
  Tap product from suggestions → It's selected!
  
Add to Cart:
  Adjust quantity with +/- buttons → Press "Add to Cart"
  
Checkout:
  Press "Proceed to Checkout" → Confirm order
